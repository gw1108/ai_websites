# George Wang — Portfolio Website

Source for my personal portfolio site: a single static page (HTML + one stylesheet + one image), no build step, no dependencies.

**Live site: https://georgetangwang.github.io/portfolio/**

> Replace the URL above with your real Pages URL once the repo is published.

## Contents

| Path | What it is |
| --- | --- |
| `index.html` | The entire page — markup and page-specific CSS |
| `assets/industry.css` | Design tokens and component styles (Industry design system) |
| `assets/george-wang.jpg` | Profile photograph |
| `.nojekyll` | Tells GitHub Pages to serve files as-is, no Jekyll processing |

## Run locally

Open `index.html` in a browser. That's it. (Or `python -m http.server` from this folder and visit http://localhost:8000.)
